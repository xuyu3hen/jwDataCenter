# 机务系统数字化管控平台手机端APP

## 1. 现状

目前各级管理人员通过统一的平台网址在电脑端登录机务数字化管控平台，进行业务查询或操作。受制于办公网络和设备限制，管理效能不高，特别是现场管理人员对于实现手机端违章违纪录入的需求较为迫切。“违章违纪管理”是抓标准化作业、提升基础业务水平的重要手段之一，目前存在部分违章提报不严谨、违章与职工见面不及时、职工对“一般违章”不重视等问题。

实现移动互联，实时查看数据、录入推送、手机在线处理的功能，提升操作便捷性、职工参与度，促进管理效能、作业标准提升。

## 2. 设计思路

1. **实现数据在线查询**。从手机端登录可查看机务系统数字化管控平台 200 项指标、31 张报表、日报、违章违纪、双百赛成绩等内容。
2. **违章违纪实时录入**。管理人员可实时录入发现的违章违纪，提高操作便捷性。移动互联，实时录入推送，手机在线处理的功能。
3. **违章违纪确认**。对录入系统的违章责任人进行一对一推送确认，由责任人进行确认或申诉，对确认无误的违章自动录入系统，对申诉的违章由车间主管违章违纪的管理员进行确认审核，并将审核结果推送责任人反馈。

### 业务流程图示
- **录入**：手机录入 / 网页端录入 -> 违章违纪
- **确认与申诉**：APP信息推送 -> 确认 / 申诉
- **日志与反馈**：确认日志 / 申诉日志 <- 反馈审核结果

## 3. 功能概述

### 3.1 权限设置
手机 APP 权限设置同电脑端一致，分层级、车间级权限，区分查看范围。
- **管理人员**：各部门分管理员和操作员账号。班组长、指导司机、其他车间管理人员账号具有手机违章录入、违章查看权限，本车间百安或百台赛成绩查看。
- **职工本人**：可以查看自己的违章违纪（提报人、提报部门隐藏不显示）、百安或百台成绩。

### 3.2 数据录入
手机 APP 端，数据平台网页端均可进行录入，录入后进入数据平台的“违章违纪管理系统”。

### 3.3 数据推送
对录入系统的违章责任人根据注册信息的账号（建议为身份证号），进行一对一推送。

### 3.4 违章确认
- 推送至责任人的违章，设置 **【确认】** 选项，责任人确认后系统自动显示确认时间。
- **时效与提醒**：确认时效为自推送后 **72 小时**内。若超过 24 小时未确认，在第 24 小时，48 小时，66 小时分别再次推送确认提醒；超过 72 小时未确认，视为确认。
- 系统自动按所在车间保存“确认日志”。

### 3.5 违章申诉
- 推送至责任人的违章，设置 **【申诉】** 选项，并填写申诉理由。
- 对申诉的违章由车间主管违章违纪的管理员进行申诉审核，设置 **【申诉成功】**、**【申诉驳回】** 选项，并填写审核意见，审核完毕后将审核结果及审核意见推送至申诉人。
  - **申诉成功**：由车间主管违章违纪的负责人在手机端或者网页端进行修改操作。
  - **申诉失败（驳回）**：设置 **【同意】**、**【分析】** 选项。
    - 选择 **【同意】** 后，该违章显示为“已确认”。
    - 对审核结果不认可的，选择 **【分析】** 后，将结果推送至审核人，审核人应及时组织相关人员召开分析会。
    - **申诉失败时效与提醒**：确认时效为自推送后 **72 小时**内。若超过 24 小时未确认，在第 24 小时、48 小时、66 小时分别再次推送确认提醒；超过 72 小时未确认，视为同意申诉结果。
